# 言えた

英会話で言えなかった一言を、毎日の瞬間英作文で練習するWebアプリ。

**アプリ：https://tamakisuguru23-cloud.github.io/ieta/**

## 使い始める（iPhone）

1. 上のURLを **Safari** で開く
2. 共有ボタン →「ホーム画面に追加」
3. ホーム画面の「言えた」から開く。最初の案内に沿って設定する

必ずホーム画面のアイコンから開く。Safariで開いた場合とは、データが別々になる。

## 安心して使えるように

- **料金はかからない。** 課金の画面も、アプリ内の購入もない
- **カードはあなたのスマホの中だけ。** ほかの人のスマホに出ることも、ほかの人のカードがあなたのスマホに出ることもない
- **英会話の記録をGeminiに貼るのは、あなた自身のGemini。** このアプリが記録を外に送ることはない
- **通知は1日1回まで。** オンにしたときだけ届く。設定 →「通知をオフにする」か、iPhoneの設定 → 通知 で止められる
- **位置情報・カメラ・連絡先などは使わない**

## やめるとき

ホーム画面の「言えた」を長押しして削除する。アプリの中のデータも消える。

## このリポジトリについて

アプリのコードだけが入っている。毎日の出題には [ts-fsrs](https://github.com/open-spaced-repetition/ts-fsrs)（MITライセンス）を使っている。
